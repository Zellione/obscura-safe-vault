# Suggested Commands

## First-time setup
```bash
scripts/setup.sh          # premake5 + SDL3 + image codecs (calls build_codecs.sh)
scripts/build_codecs.sh   # (re)build just the vendored image codecs into vendor/codecs-prefix
```
Prerequisites: `cmake`, `ninja`, a C++23 compiler, and **nasm** (for libaom / AVIF).

## Generate build files
```bash
scripts/gen.sh            # Ninja (default) — also regenerates compile_commands.json
scripts/gen.sh --gmake    # GNU Make fallback
```

## Build
```bash
scripts/build.sh          # Debug
scripts/build.sh --release
scripts/build.sh --clean  # wipe this config's outputs first, then build (combinable with --release/--gmake)
```
`build.sh` builds the APP target only (`ninja osv_<Config>_x64` / `make osv`) — not the
aggregate config target, which would also compile osv_tests (the test project recompiles
shared src/ sources under its own fixture defines ≈ double the compile work).

## Run
```bash
build/bin/Debug/osv
build/bin/Release/osv
```

## Tests
```bash
scripts/test.sh           # build + run all tests (Debug)
scripts/test.sh --asan    # AddressSanitizer + UBSan + LSan
scripts/test.sh --release
scripts/test.sh --tsan    # ThreadSanitizer (mutually exclusive with --asan)
```
Sanitizer builds are isolated (PR #122): `--asan`/`--tsan` output to
`build/bin/<Config>-asan` / `-tsan` (own objdirs too, so plain and sanitizer
object trees stay warm side by side), and `test.sh` restores PLAIN build files
on exit after a sanitizer run — `build/bin/Debug/osv` is never instrumented and
a later `scripts/build.sh` always produces plain binaries.
⚠ `scripts/test.sh` builds the WHOLE config (osv + osv_tests — a compile error in either
would otherwise be missed); `scripts/build.sh` builds only osv, so test-side compile
breakage surfaces at `test.sh` time, not `build.sh` time (`-Werror` branch-wide since
audit-improvements).
Clang parity check (matches CI's clang leg): `bin/premake5 ninja --cc=clang && ninja -k0 -f build.ninja`,
then restore with `scripts/gen.sh`.

No-FFmpeg parity check (matches CI's `tests-no-av` leg — the configuration where
every `#ifdef OSV_VENDORED_AV` takes its `#else` branch):
```bash
bin/premake5 --no-av ninja && ninja Debug_x64 && ./build/bin/Debug/osv_tests
scripts/gen.sh            # restore the normal (FFmpeg) build files afterwards
```
`--no-av` ignores the built FFmpeg prefix instead of deleting it, so nothing has
to be rebuilt either way. Expect ~1514 tests instead of ~1677: the GIF/video
suites compile out, while animated WebP still runs (libwebp is not optional).

## ASAN-instrumented codecs (audit-improvements)
```bash
scripts/build_codecs.sh --asan   # → vendor/codecs-prefix-asan/ (separate prefix, gitignored)
scripts/test.sh --asan           # premake prefers the asan prefix when it exists
```

## Import benchmark (audit-improvements)
```bash
OSV_BENCH=1 scripts/test.sh                      # N=100 bench (tmpfs)
OSV_BENCH=1 OSV_BENCH_DIR=$HOME/.cache scripts/test.sh   # real-disk numbers
```


## Perf tracing (Phase 58)
```bash
OSV_PERF_LOG=1 build/bin/Debug/osv       # traces render frames (20ms), updates, vault ops
OSV_PERF_LOG=1 build/bin/Release/osv     # Release for real-vault benchmarking
```
Fixed labels (see `platform/perf.*`): `frame(20ms)`, `app.update`, `grid.refresh`,
`grid.detail`, `search.gather`, `advsearch.rerun`, `thumb.fetch(5ms)`, `viewer.vault_changed`.
Use on a 200GB vault to verify thumbnail I/O is now async (5–20 ms intervals, not per-frame hangs).

## Serena / LSP
- `compile_commands.json` is regenerated by `scripts/gen.sh` — run after adding/moving files.
- `serena memories check` — check for stale memory references.
